# 08 - UI / UX Design

## Design Goals

-   Minimize taps during mapping.
-   Keep the map as the primary workspace.
-   Surface only the actions needed for the current step.
-   Be fully usable offline.

------------------------------------------------------------------------

# Navigation

-   Splash
-   Home
-   Journeys
-   Active Mapping
-   Validation
-   Exports
-   Settings

------------------------------------------------------------------------

# Home

Sections: - Continue Journey - New Journey - Validate Fare - Exports -
Settings

------------------------------------------------------------------------

# Journey List

Groups: - Draft - Completed

Actions: - Resume - Review - Export - Delete

------------------------------------------------------------------------

# Active Mapping Screen

Header - Journey name - Current Area - GPS accuracy - Tracking indicator

Body - Full screen map - Journey polyline - Stops - Area boundaries

Bottom Action Sheet - Add Stop - New Area - Finish Journey - Pause
Mapping

------------------------------------------------------------------------

# Dialogs

New Area - Suggest existing Area if polygon matches. - Allow override.

New Stop - Prevent duplicates inside Stop radius. - Assign Fare Level.

Journey Fare - Require fares before continuing.

------------------------------------------------------------------------

# Validation Screen

Inputs - Pickup GPS - Destination GPS

Output - Journey - Pickup Stop - Pickup Area - Destination Stop -
Destination Area - Fare - Diagnostics

------------------------------------------------------------------------

# UX Principles

-   One-handed operation.
-   Large touch targets.
-   Map always visible.
-   Confirmation only when necessary.
-   Immediate feedback after every action.
